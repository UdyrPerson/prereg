# prereg

Empreintes de pre-enregistrement (SHA-256 tronque a 16 caracteres) de projets de recherche, publiees avant toute lecture des donnees testees. L'heure de reception du push par GitHub date chaque empreinte ; le contenu des fichiers haches reste prive.

Les lignes du 2026-09-26 au 2026-10-10 ont d'abord ete publiees dans `UdyrPerson/listing-live` (`prereg/hashes.txt`, jusqu'au commit f49eb55) : c'est la que leur date fait foi. Elles sont recopiees ici pour que le registre soit complet.
